# 🎵 Music Player

A simple and responsive **Music Player** built using **HTML, CSS, and JavaScript**.

This project allows users to play songs, control playback, adjust volume, seek through a song, and switch between tracks using a clean and minimal interface.

## ✨ Features

* ▶️ Play and pause songs
* ⏮️ Previous and next song controls
* 🎵 Displays song title and artist
* 🖼️ Displays album artwork
* ⏱️ Real-time playback progress
* 🔍 Seek through the song using the progress bar
* 🔊 Volume control
* 🔄 Automatically plays the next song when the current song ends
* 🎨 Dynamic background gradient based on the currently playing song
* 💿 Animated album artwork while playing

## 🛠️ Technologies Used

* **HTML5** – Structure of the music player
* **CSS3** – Styling, layout, animations, and responsive design
* **JavaScript** – Audio controls, song management, progress tracking, and UI updates
* **HTML5 Audio API** – Handling audio playback

## 🚀 How to Run

1. Clone the repository:

```bash
git clone <your-repository-url>
```

2. Open the project folder.

3. Open `index.html` in your browser.

4. Select a song and start listening 🎧
